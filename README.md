**Mechanistic Interpretability · Transformers · GPT-2 · PyTorch · 3D Visualization**

### [StageGround](https://github.com/CG-Brian/stage-ground)
Clinical LLM evaluation on TCGA pathology reports, studying whether correct TNM predictions are actually supported by the source evidence.

**Clinical NLP · LLM Evaluation · Grounding**

**Genomics · PyTorch · NLP for Biological Sequences**
